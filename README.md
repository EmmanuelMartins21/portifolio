# Portfólio Pessoal – Emmanuel Martins

Landing page desenvolvida apenas com HTML, CSS e JavaScript puro.

## Estrutura
- `index.html`: página principal
- `css/style.css`: estilos principais
- `js/main.js`: scripts principais
- `assets/`: imagens e ícones

## Cores
- Branco, azul e cinza (neutras)

## Seções
- Header, Sobre, Tecnologias, Projetos, Contato, Footer

## Como usar
Abra o arquivo `index.html` em seu navegador.
